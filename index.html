⚙ Configurazione Sync

Inserisci un GitHub Personal Access Token per sincronizzare i dati tramite un Gist segreto. Usa un token fine-grained con il solo permesso Gists: Read and write e una scadenza, e revocalo da GitHub se non lo usi più. Il token viene salvato solo nel localStorage di questo browser.

Un Gist segreto non compare nelle ricerche, ma chiunque abbia il suo link può leggerlo. Con una passphrase i dati vengono cifrati prima di lasciare il browser: sul Gist resta solo testo illeggibile. Usa la stessa passphrase su tutti i dispositivi e conservala: senza non si possono recuperare i dati del Gist.
