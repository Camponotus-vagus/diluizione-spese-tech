⚙ Configurazione Sync

Inserisci un GitHub Personal Access Token con scope gist per sincronizzare i dati tramite un Gist privato. Il token viene salvato solo nel localStorage del browser. Per sicurezza usa preferibilmente un token fine-grained con permesso limitato ai Gist e una scadenza breve, e revocalo da GitHub se non lo usi più.
